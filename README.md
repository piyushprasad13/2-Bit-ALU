# 2-Bit Arithmetic Logic Unit (ALU)

A **2-Bit Arithmetic Logic Unit (ALU)** designed and simulated in **Proteus**. The project demonstrates the implementation of basic arithmetic and logical operations using digital logic gates.

## Project Overview

An Arithmetic Logic Unit is a digital circuit that performs arithmetic and logical operations on binary data.

This project implements a simple **2-bit ALU** capable of performing:

- Addition
- Subtraction
- AND operation
- OR operation

The required operation is selected using control inputs, and the corresponding output is generated by the ALU circuit.

## Features

- 2-bit binary input processing
- Arithmetic operations:
  - Addition
  - Subtraction
- Logical operations:
  - AND
  - OR
- Operation selection using control inputs
- Designed and verified using Proteus
- Built using fundamental digital logic concepts

## Block-Level Working

The ALU receives two 2-bit operands:

- **A = A1 A0**
- **B = B1 B0**

The inputs are processed by separate arithmetic and logic sections. The required operation is selected using control signals, and the selected result is provided as the ALU output.

### Operations

| Operation | Function |
|---|---|
| Addition | A + B |
| Subtraction | A - B |
| AND | A AND B |
| OR | A OR B |

## Circuit Implementation

The complete 2-bit ALU circuit was designed and simulated in **Proteus** using digital logic gates and supporting logic components.
